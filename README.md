# Alliance Architectural CNC & Interiors

> **Complete Interior & Exterior Design Solutions** — CNC Router, Laser Cutting, Custom Jali Screens & Luxury Fit-outs.

## Repository Structure

```

    ├── index.html
```

## Getting Started

```bash
# Navigate to the frontend
cd frontend

# Install dependencies
npm install

# Start the dev server (http://localhost:3000)
npm run dev
```

## Build for Production

```bash
cd frontend
npm run build
# Output: frontend/dist/
```

## Tech Stack

- **React 18** — UI components
- **Vite 5** — Dev server & build tool
- **Vanilla CSS** — Custom design system (dark theme, crimson accent)
- **Lucide React** — Icon library
