# PP Neue Machina Inktrap Fonts

Place your PP Neue Machina Inktrap font files in this folder (`frontend/public/fonts/`).

The `@font-face` rules in `src/index.css` automatically detect and load any of the following filenames:

### Regular (400)
- `PPNeueMachina-InktrapRegular.woff2` (recommended)
- `PPNeueMachina-InktrapRegular.woff`
- `PPNeueMachina-InktrapRegular.otf`
- `PPNeueMachina-InktrapRegular.ttf`
- `PPNeueMachina-Regular.woff2`
- `neue-machina-regular.woff2`

### Medium (500)
- `PPNeueMachina-InktrapMedium.woff2`
- `PPNeueMachina-InktrapMedium.otf`
- `PPNeueMachina-InktrapMedium.ttf`

### Bold (700)
- `PPNeueMachina-InktrapBold.woff2`
- `PPNeueMachina-InktrapBold.otf`
- `PPNeueMachina-InktrapBold.ttf`

### Ultrabold / Black (800 / 900)
- `PPNeueMachina-InktrapUltrabold.woff2`
- `PPNeueMachina-InktrapBlack.woff2`
- `PPNeueMachina-InktrapUltrabold.otf`

*(Note: If you have PP Neue Machina installed locally on your Windows/Mac system, the browser will also automatically detect and use it immediately via `local()` declaration).*
